Sobre este juego

Random Dice - Tap to Roll te permite lanzar de uno a seis dados con animación y sonido. La suma se calcula automáticamente, así que está lista para juegos de mesa, decisiones rápidas o cuando necesites un dado.

¿Prefieres el navegador? Prueba el lanzador de dados online, con dados de d4 a d20.

Características

  • Lanza de 1 a 6 dados a la vez
  • Animación de dados
  • Efectos de sonido
  • Suma automática
